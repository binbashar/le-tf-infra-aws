# Layers exempt from the PRM `aws-apn-id` tag check.
#
# A layer belongs here only when one of these is true:
#   (a) it creates no AWS resources at all (Kubernetes/Helm providers only), or
#   (b) every AWS resource it creates is untaggable, or
#   (c) the upstream module it depends on exposes no `tags` variable, so the
#       layer cannot pass tags through without a module change.
#
# "This service is not in the PRM Included Services list" is NOT a reason --
# AWS recommends instrumenting every service so that coverage expansions need
# no further code changes. Tagging an unsupported service is simply ignored.
#
# One layer path per line, relative to the repository root, with the reason.
